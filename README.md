## Features

- Add, view, update, and delete products
- Input validation for product details
- Binary Search on product names or IDs
- Sorting using standard algorithms(Selection, Insertion and Merge Sorting)


## Technologies Used

- **Language:** Java
- **IDE:** Apache NetBeans
- **Data Storage:** In-memory (ArrayList and LinkedList)
- **Algorithms:** Binary Search, Sorting
