# Umbra – Handicraft Management System
UMBRA Ceramics – Where Tradition Meets Creativity
Discover handcrafted wonders with Umbra, a comprehensive system designed to manage and showcase traditional handicraft products.

Umbra helps artisans and craft businesses by efficiently managing handicraft products by providing an intuitive user interface for performing CRUD operations. The system empowers local artisans by supporting efficient product organization, and is focused on preserving traditional crafts in a digital form.

## Features

- Add, view, update, and delete products
- Real-time viewing of product details
- Simple and intuitive user interface for smooth navigation and operations
- Input validation for product details
- Binary Search on product names or IDs
- Sorting using standard algorithms(Selection, Insertion and Merge Sorting)


## Technologies Used

- **Language:** Java
- **IDE:** Apache NetBeans
- **Data Storage:** In-memory (ArrayList and LinkedList)
- **Algorithms:** Binary Search, Sorting

## How to Run

1. **Install NetBeans IDE**  
   Download from: https://netbeans.apache.org/download/

2. **Install JDK 23** (if not already installed)  
   Download from: https://www.oracle.com/java/technologies/javase/jdk23-archive-downloads.html

3. **Open the Project in NetBeans**  
   - Go to `File → Open Project`  
   - Select the `crafta` folder

4. **Clean and Build**  
   - Right-click the project name (`crafta`) → `Clean and Build`

5. **Run the Main File**  
   - Right-click `Craft_23048590DixitaBajracharya.java` → `Run File` 

6. **Use the App via Swing GUI**  
   - The application window will open  
   - Use buttons to Add, View, Update, Delete products
