## ✨ Features

- ✅ Add, view, update, and delete products
- 🔒 Input validation for product details
- 🔍 Binary Search on product names or IDs
- 📊 Sorting using standard algorithms (e.g. bubble sort or selection sort)
- 🧵 All written in beginner-friendly Java (no external libraries)
---

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** Apache NetBeans
- **Data Storage:** In-memory (ArrayList or custom structure)
- **Algorithms:** Binary Search, Sorting (Bubble/Selection)
